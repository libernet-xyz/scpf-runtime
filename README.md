## Overview

The **Starkom Compact Proof Format**, or **SCPF**, is a highly gas-efficient binary format for
encoding Starkom proofs off-chain and decoding them in the Ethereum Virtual Machine.

We recommend using SCPF only when sending Starkom proofs to an Ethereum smartcontract, otherwise
you can use Starkom's native protobuf encoding.

This crate contains the Rust runtime used by the Starkom encoders and decoders generated by the SCPF
compiler. (Note that the use case for decoders is marginal, as decoding virtually always happens on
the EVM.)
